### Key Fix Summary

The main issue was that dark mode button styles only changed the hover state, not the default background. The fix:
- Before: `.dark .btn-primary { @apply hover:bg-moss; }`
- After: `.dark .btn-primary { @apply bg-forest-light hover:bg-moss; }`

This ensures primary buttons use the lighter forest green in dark mode as specified, providing better visual contrast against the dark backgrounds.
